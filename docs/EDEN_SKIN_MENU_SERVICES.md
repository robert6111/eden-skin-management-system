# Eden Skin service menu setup

This release includes the Eden Skin menu services extracted from the uploaded price-list images.

## What was added

Active services are grouped into:

- Facial Treatments
- Body Waxing
- Facial Wax
- Body Facials
- Slimming Therapy

The old demo salon services are not deleted. The setup action marks old template services inactive so historical sales and appointments do not break.

## How to apply to an existing installed system

Open:

Services & Stock → Product Consumption

Click:

Add / Update Eden Skin Services

This will:

- add missing Eden Skin services
- update the Eden Skin prices and descriptions
- add missing products used by those services
- add automatic product-consumption rules
- keep your custom consumption quantities if they already exist

Click:

Reset to Eden Skin Recommendations

only when you want to replace existing consumption quantities with the recommended defaults.

## Stock deduction rule

Products do not decrease when the booking is made.
Products decrease when the service is sold/paid in POS.

Example:

Deep Cleansing Facial uses 10 ml Facial Cleanser and 15 grams Facial Mask.
When one Deep Cleansing Facial is sold in POS, those quantities are deducted automatically.
