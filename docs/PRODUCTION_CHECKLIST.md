# Eden Skin — Delivery Checklist

Before customer handover, confirm:

- [ ] Clean package contains no `config.php`.
- [ ] Clean package contains no `storage/installed.lock`.
- [ ] `storage/backups` contains no developer/customer SQL dump.
- [ ] Installer opens on a fresh XAMPP setup.
- [ ] Business displays as **Eden Skin — Skin Beauty Aesthetics**.
- [ ] Owner account can sign in.
- [ ] Staff, services and prices are reviewed.
- [ ] Customer can be created and retrieved.
- [ ] One test sale shows the correct customer, items, staff, quantity, unit price, discount and line total.
- [ ] Receipt prints correctly.
- [ ] Public booking creates only one appointment per submission.
- [ ] Refreshing the success page does not create another appointment.
- [ ] `storage`, `database`, `docs`, and `cron` cannot be browsed directly through Apache.
- [ ] Manual WhatsApp workflow is explained; no promise of automatic provider delivery is made.
- [ ] Manual backup can be created and downloaded.
- [ ] A restore procedure is understood/tested before relying on it in production.
- [ ] Customer receives Owner credentials securely and is told to change/guard the password.
